MySQL Workbench & Database Setup

Database: foodflow_db · Port: 3306

Current Connection Status:
🟡 Checking MySQL Server...
To store everything directly in MySQL, follow the 3 steps below.

⚡ How to connect MySQL Workbench:

Step 1: Open schema.sql in MySQL Workbench

Launch MySQL Workbench, connect to your Local Instance (port 3306), go to File → Open SQL Script and select:

schema.sql (in your FoodFlow_Fresh directory)

Click the ⚡ Execute lightning bolt button in MySQL Workbench to create all 16 tables and seed data!

Step 2: Configure MySQL Password in .env

Open .env in your project directory and set your MySQL password:

DB_PASSWORD=your_mysql_password
Step 3: Start Node.js Express Backend API

Open terminal in the project directory and run:

npm install && npm start
